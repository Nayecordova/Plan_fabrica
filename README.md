\# Proyecto Ágil



Repositorio de práctica para aprender Git en Windows.



\## Objetivo

Gestionar el backlog, los riesgos y los cambios de un proyecto utilizando control de versiones.



\## Estado

Proyecto iniciado.



\## Metas Operativas y Procesos

Metas Operativas:

\-Mantener organizada y actualizada la lista de tareas pendientes del proyecto.

\-Registrar los cambios mediante commits claros y ordenados.

\-Fomentar el trabajo colaborativo mediante el uso de Git y GitHub.

Procesos:

\-Registrar cada modificación mediante confirmaciones con descripciones claras.

\-Crear ramas y administrar ramas para nuevas funcionalidades o cambios.

\-Mantener la documentación del proyecto actualizada conforme avanza el proyecto.
